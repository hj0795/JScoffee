        공용 시간표 관리 안내

        1. 공용 DB에서 함께 사용
          모든 이용자가 같은 서버의 시간표를 불러옵니다. 인터넷에 연결된 이용자의 화면에는 저장된 변경 내용이 실시간으로 반영됩니다.
        2. 자료 교체
          관리자 비밀번호를 입력한 뒤 PDF를 올리세요. 서버 저장이 완료되면 선택한 종류의 자료 전체가 새 파일로 교체됩니다. PDF를 읽거나 검증하지 못하면 기존 자료를 유지합니다.
        3. 직접 수정
          직책·담임 이름은 입력 후 자동 저장됩니다. 회의 추가와 삭제도 모든 이용자에게 반영됩니다. 저장 오류가 표시되면 다시 저장하거나 최신 자료를 불러오세요.

        관리자 인증은 서버에서 확인합니다. 현재 창을 새로 열거나 새로고침하면 다시 로그인합니다.
